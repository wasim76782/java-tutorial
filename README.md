## ▶️ How to Run Java Programs

1. Install the [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/downloads/).
2. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

3. Navigate to the project directory:

   ```bash
   cd "java tutorial"
   ```

4. Compile a Java file:

   ```bash
   javac hash.java
   ```

5. Run the compiled class:

   ```bash
   java hash
   ```

**Note:** Replace `hash` with the appropriate Java class name for your program.
